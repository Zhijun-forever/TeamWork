非遗数字化管理平台 · 页面地图

全部页面按 Element 组件规范重做：默认主色 #409EFF、白色卡片、浅灰背景、4px 圆角、清晰表格与表单。 不含古风装饰，纯静态 HTML + 本地 CSS / JS，双击即可离线浏览。

Element 设计规范 23 个页面 零外部依赖 1440 / 390 响应式

设计规范

Element Default
主色
#409EFF
成功 #67C23A、警告 #E6A23C、危险 #F56C6C、信息 #909399；背景 #F5F7FA。
组件
38px 控件 · 4px 圆角
按钮、输入框、选择器、表格、标签、分页、弹窗、步骤条、时间线统一对齐 Element。
技术
纯静态 · 可直接迁移
无 Vue / 无 CDN；结构可拆为 Jinja2 模板，接口在 api.js，交互在 app.js。
适配
1440 / 768 / 390
公众端导航可横滑，后台侧栏在窄屏变为抽屉；表格支持横向滚动。

数据来自公开名录与项目保护单位资料。页面操作通过前端接口层提交，接口地址与请求格式见接口清单。
