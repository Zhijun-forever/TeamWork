> 对应前端目录：`prototype-element/`  
> 接口与数据基线：《系统接口清单 V1.1》《数据库表设计 V1.1》  
> 更新日期：2026-11-25

## 1. 项目定位

面向省 / 市级非遗保护中心、项目保护单位与公众的轻量数字化平台。前端覆盖四类角色、项目管理生命周期、分类检索、AI 问答、审核归档、用户与系统运维。

- 前端技术：HTML5 + CSS3 + 原生 JavaScript，无 Vue、无 Element Plus、无构建步骤
- 视觉体系：Element 默认组件规范
- 数据：公开名录、项目保护单位资料与模拟数据结构
- 当前状态：后端未完成，前端默认运行在 mock 模式；接口路径、参数与字段已按 V1.1 对齐

## 2. 运行方式

### 直接打开

双击 `index.html`，进入页面地图；所有页面使用相对路径，可离线浏览。

### 本地服务

```bash
cd prototype-element
python -m http.server 8000
```

访问 `http://127.0.0.1:8000/`。

### 接口模式

`assets/js/api.js` 默认 mock 模式。切换真实后端：

```html
<script>
  window.FEIYI_CONFIG = {
    mode: "live",
    baseURL: "http://127.0.0.1:8000"
  };
</script>
<script src="assets/js/api.js"></script>
<script src="assets/js/app.js"></script>
```

建议在 `base.html` 中输出 CSRF：

```html
<meta name="csrf-token" content="{{ csrf_token() }}">
```

## 6. 接口对接

### 通用约定

- Base URL：开发环境 `http://127.0.0.1:8000`
- 认证：Flask-Login 会话 Cookie；`live` 模式请求携带 `credentials: same-origin`
- CSRF：读取 `<meta name="csrf-token">`，写入 `X-CSRFToken`
- JSON 成功：`{"code":"OK","message":"success","data":{...}}`
- JSON 失败：`{"code":"ERROR_CODE","message":"用户可读信息","data":null}`
- 状态码：400 / 401 / 403 / 404 / 409 / 413 / 429 / 500 / 503
- 分页：`page` 从 1 开始，列表默认 12 条 / 页
- 排序：`sort ∈ {views, updated_at, created_at, archived_at}`，`order ∈ {asc, desc}`
- 上传：jpg/png/webp ≤10MB，PDF ≤20MB，UUID 文件名

## 8. 详细讲解流程（建议 6–8 分钟）

1. **页面地图**：打开 `index.html`，介绍 23 页与公众 / 后台两部分。
2. **公众端**：首页 → 项目库筛选 → 项目详情四个标签页 → 帮助中心搜索“密码”。
3. **登录与角色**：登录页一键填入 `manager01`，跳转后台项目库；说明侧栏只保留项目管理者可用菜单。
4. **项目管理**：新建项目 → 保存草稿 / 提交审核；编辑已驳回项目 → 重新提交。
5. **审核闭环**：用 `admin01` 登录 → 审核工作台 → 切换待审项目 → 通过或驳回（驳回必填意见）。
6. **认证与归档**：项目认证审批 → 归档管理恢复 → 修改申请处理。
7. **AI 问答**：公众端提问“苗族刺绣有哪些代表项目？”，展示回答、引用、剩余次数；提问超范围问题展示拒答。
8. **通知中心**：顶栏铃铛 → 筛选未读 → 标为已读 / 全部已读；说明未读数同步侧栏与顶栏。
9. **接口与运维**：说明 V1.1 的 21 个接口、mock / live 切换、备份与索引重建、审计日志。
10. **移动端**：浏览器压到 390 宽，展示导航横滑、后台抽屉侧栏、表格横向滚动。
